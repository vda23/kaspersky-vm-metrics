# assets/

Файлы, которые не хранятся в git. Положите их сюда перед сборкой архива (`bash tools/build_dist.sh`) или запуском демо.

| Файл | Назначение |
|---|---|
| `KasperskySans-Regular.ttf` | шрифт интерфейса; без него используется системный |

Логотип сервиса и значок вкладки встроены в `kaspersky-vm-metrics.py` из `web/brand.png`; добавлять их сюда не нужно. При необходимости встроенный логотип можно заменить своим: `logo.svg|png` (обе темы), `logo-dark.*` и `logo-light.*` (отдельно для тёмной и светлой темы), `favicon.svg|png` (значок вкладки, квадратный, от 64×64 px).
