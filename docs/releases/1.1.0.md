В версии 1.1.0 сервис мониторинга Kaspersky VM и его установщик перенесены с Python на Go. Для запуска готового пакета на сервере достаточно системных утилит Linux. Сервис по-прежнему показывает состояние шести служб, журналы и отчёты и передаёт события CEF в SIEM. Панель и её веб-ресурсы встроены в бинарник.

### Установка и обновление

Скачайте архив для своего сервера и файл `SHA256SUMS`. Для `x86_64` нужен `linux-amd64`, для `aarch64` — `linux-arm64`. В каталоге загрузки выполните `sha256sum --check --ignore-missing SHA256SUMS` и распакуйте архив после успешной проверки.

| Установленная версия | Команда из каталога распакованной 1.1.0 |
|---|---|
| Первая установка или обновление с 1.0.0 | `sudo bash install.sh` |
| Тестовая 1.2.0-dev | `sudo bash install.sh --force` |

Переход с тестовой сборки требует подтверждения, поскольку её номер выше. Установщик сохраняет порт, сертификат, закрытый ключ, настройки SIEM и отчёты. Для возврата к предыдущей установке выполните `sudo bash /opt/kaspersky-vm-metrics/install.sh --rollback`. Для возврата к 1.0.0 на сервере нужен Python 3.

### Проверки

На нативных Linux amd64 и arm64 выполняются тесты с детектором гонок, установка поверх 1.0.0 и 1.2.0-dev, откат, запуск скачиваемого пакета, проверка HTTPS и уведомлений systemd. На amd64 дополнительно проверяется дашборд в Chromium. Испытания с действующими Kaspersky VM, PostgreSQL и KUMA, а также 24-часовой прогон перечислены в [плане тестирования](https://github.com/vda23/kaspersky-vm-metrics/blob/v1.1.0/AGENTS.md).
